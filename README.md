# Arz MODS WebSell • Cosmic Digital Store (Widescreen Edition)

Премиальная локальная витрина цифровых товаров (сборок, скриптов, графики, аксессуаров) с широкоформатным **Cosmic / Deep Space** интерфейсом, интерактивным звездным полем и концепцией **Tribute.tg**.

---

## 🚀 Быстрый запуск

1. Дважды кликните по файлу [**`start.bat`**](file:///E:/Arz%20MODS/websell/start.bat).
2. Браузер откроет витрину:
   - **Главная витрина (каталог):** [http://localhost:5000](http://localhost:5000)
   - **Прямая страница сборки Jimi Hopper:** [http://localhost:5000/p/ByO](http://localhost:5000/p/ByO)

---

## 🌌 Новые космические возможности (Cosmic Update):

1. **Широкоформатный интерфейс (Widescreen Desktop)**:
   - Снято ограничение по ширине (контейнер до 1360px на мониторах).
   - Адаптивная космическая сетка товаров (3–4 карточки в ряд на ПК, с 3D-наклоном при движении мыши).

2. **Интерактивные космические эффекты**:
   - Анимированное звездное поле на HTML5 Canvas (мерцание сотен звезд, параллакс за курсором мыши, пролетающие кометы/падающие звезды).
   - Мягкие дрейфующие неоновые туманности (Cyan, Electric Blue, Violet Aurora).
   - Стеклянный матовый неоновый интерфейс (Glassmorphism с мощным размытием backdrop-filter).

3. **2-Колоночная страница товара (`/p/ByO`)**:
   - **Слева:** Огромная медиа-сцена с обложкой, неоновым ореолом, кнопкой зума на весь экран (Lightbox), матрицей характеристик (*FPS Boost, Шейдеры, Кастомные аксы, Гарантия*) и форматированным описанием.
   - **Справа:** Плавающая консоль оформления заказа с крупной ценой в градиенте, бейджем мгновенного доступа, микро-карточкой автора и кнопкой покупки в Telegram.

4. **Полный функционал управления**:
   - Добавление и редактирование любых товаров без знания кода.
   - Загрузка картинок прямо со своего компьютера.
   - Настройка названия магазина, аватарки и Telegram контакта в один клик.
   - Локальная база SQLite (`data/store.db`), стандартный Python 3 без зависимостей.
